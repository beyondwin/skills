# Sources

This skill does not pin an external explanation corpus.

Only URLs fetched in the current turn may appear as verified sources. If none were
fetched, omit the citation heading; an unverified claim note may still appear in the
body. Never invent paper or statute identifiers.

Stable general principles need no unnecessary lookup. Claims depending on date,
jurisdiction, or material uncertainty must be verified or explicitly unverified.
When host policy and user constraints allow, check primary sources. If lookup is
unavailable or the user disallows it, mark the dependent claim unverified and state
the date/jurisdiction limitation without inventing details.
