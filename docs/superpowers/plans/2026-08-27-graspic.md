# graspic Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Install a personal Agent Skill `graspic` at `$GROK_HOME/skills/graspic` that explains one machine at a chosen rung (그림 / 길 / 뼈대 / 허점) without touching the public two-skill catalog.

**Architecture:** The installed payload is only `SKILL.md` plus four `references/` files. Contract tests and pressure-scenario notes live under `$GROK_HOME/eval/graspic/` and are never copied into the skill directory or into `beyondwin/skills`. The public plugin must still discover exactly `korean-writing-editor` and `image-workbench`.

**Tech Stack:** Agent Skills (`SKILL.md` + markdown references), Python 3.11+ `unittest` for file contracts, host subagents for pressure scenarios, Grok mermaid/markdown.

**Spec:** `docs/superpowers/specs/2026-08-27-graspic-design.md`

- [ ] **Step 3: Write failing contract tests**

```python
#!/usr/bin/env python3
import json
import os
import unittest
from pathlib import Path

def grok_home() -> Path:
    raw = os.environ.get("GROK_HOME")
    return Path(raw).expanduser().resolve() if raw else (Path.home() / ".grok").resolve()

def skill_root() -> Path:
    return grok_home() / "skills" / "graspic"

def public_repo() -> Path:
    return Path.cwd()

class GraspicContractTests(unittest.TestCase):
    def test_name_matches_directory(self):
        text = (skill_root() / "SKILL.md").read_text(encoding="utf-8")
        self.assertRegex(text, r"^---\n(?:.*\n)*name: graspic\n", flags=0)
        self.assertTrue(skill_root().name == "graspic")

    def test_description_excludes_eli5_and_workflow(self):
        text = (skill_root() / "SKILL.md").read_text(encoding="utf-8")
        fm = text.split("---", 2)[1]
        self.assertNotIn("eli5", fm.lower())
        self.assertNotIn("바로 / 하나", fm)
        self.assertIn("Use when", fm)
        self.assertIn("/graspic", fm)

    def test_payload_files_exist(self):
        root = skill_root()
        for rel in (
            "SKILL.md",
            "references/output.md",
            "references/visuals.md",
            "references/korean.md",
            "references/stakes.md",
        ):
            self.assertTrue((root / rel).is_file(), rel)

    def test_payload_excludes_eval_and_html_templates(self):
        names = {p.name for p in skill_root().rglob("*") if p.is_file()}
        self.assertNotIn("test_contract.py", names)
        self.assertNotIn("cases.json", names)
        joined = "\n".join(
            p.read_text(encoding="utf-8") for p in skill_root().rglob("*.md")
        )
        self.assertNotIn("<html", joined.lower())

    def test_public_catalog_still_two_skills(self):
        skills = Path.cwd() / "skills"
        found = sorted(p.name for p in skills.iterdir() if p.is_dir())
        self.assertEqual(found, ["image-workbench", "korean-writing-editor"])

    def test_cases_file_parses(self):
        path = Path(__file__).with_name("cases.json")
        data = json.loads(path.read_text(encoding="utf-8"))
        ids = [c["id"] for c in data["cases"]]
        self.assertEqual(
            ids,
            ["gate-dump-01", "html-01", "type-cmp-01", "scope-01", "ko-gloss-01"],
        )

if __name__ == "__main__":
    unittest.main()
```

## Classify

Say one line before any question so the user can override:

> {slice}네. **{rung}**로 보고, {particle}를 따라갈게.

Paths:

| Path | When | Do |
| --- | --- | --- |
| 바로 | slice + rung already present | One-line plan. Explain next if unsurprising. |
| 하나 | one required slot missing | Ask one closed question. |
| 자르기 | blob noun | Three slices + Other. No essay. |

Do not stack two questions. Do not re-ask a filled slot. Do not survey genre, audience, or tone.

## Slots

Required before EXPLAIN: `slice`, `type`, `rung`, `language`.

Infer `type` when the verb is obvious (`vs` → 비교, `어떻게 고치냐` → 절차, `왜/원리` → 개념, `흐름` → 흐름). Ask type only if the guess would change the output.

Missing-slot order: slice → rung → language.

Rung picker (recommendation first):

- **길** — 누가 무엇을 넘기는지 (default)
- **그림** — 한 장
- **뼈대** — 갈림길과 실패
- **허점** — 이 그림이 금 가는 곳

Silent aliases (never print numbers or ages): 쉽게/한눈에/한 장/`5` → 그림; 흐름/원리/따라가/`10` → 길; 내부/실무/속/`15` → 뼈대; 한계/깊게/예외/반례/`20` → 허점.

If the prompt already uses domain words (`rebase`, `TTL`, `Raft`), default **뼈대** unless they named 그림.

Intent line:

> {slice}를 **{rung}**로, {particle}를 따라갈게. 안 다루는 것: {out of scope}.

Do not wait for a nod when they already chose the rung. Pause when the slice is surprising or the topic is medical, legal, or financial — then read `references/stakes.md`.

## After EXPLAIN

One next move only:

- 다음 칸 (그림→길→뼈대→허점)
- 흐린 홉 하나
- 다른 각도 (비교 / 절차 / 실패)
- 한 줄로 되말하기
