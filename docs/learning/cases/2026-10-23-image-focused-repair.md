# 작은 검수 수정이 실제 납품 실패를 줄이는가?

결정일·기록일: 2026-10-23
관련 작업: image-workbench 2.1.6 후보
결과: 2.1.6 반영. Codex의 특정 요구 해석 결함 수정, 최종 핵심 조건·구도 확인. Grok 단독 검수 개선은 미입증
근거 성격: 사용자 재요청과 기존 실패 원본을 직접 확인한 당시 자료. 기존
24장은 이미 확인한 개발 자료이며 새 독립 평가로 부르지 않는다.

## 시작한 문제와 선택

사용자는 G 미채택에서 끝내지 말고 실제 효과가 나는 수정, 최종 생성 검증,
커밋을 요구했다. 동시에 반복 실험과 과한 복잡성을 줄이라고 했다. 이전
[판단](2026-10-23-image-evidence-review.md)은 보존한다.

새로운 표본과 판정기를 늘리는 대신 잘못된 요구 해석을 고친다. 보이는 대상을
위치별로 센 뒤 비교하고, 프레임 안에 있음·부품 식별·완전 무가림을 구분한다.
관찰한 반례가 없으면 요구를 강화해 탈락시키지 않는다. 통과한 후보는 보존하고
필수 실패에만 원문 전체를 유지한 한 가지 보정을 한다.

## 검증 계획

이미 확인한 개수 실패·가림 실패·정상 겹침 원본 세 장에 기존판과 개선판을
각 한 번 적용한다. 같은 원본·요청·모델·도구·한 번 보정 예산이다. 새 생성
최종본까지 직접 열고 익명 독립 검수한다. 숫자를 늘려 유의성을 얻으려 하지
않으며 전체적인 우월성 대신 재현된 결함의 제거와 최종 납품을 확인한다.
[사전 고정 기준과 결과](../../research/2026-10-image-focused-repair/README.md)에
실제 호출·비용 대용 지표·한계를 함께 남긴다.

## 확인한 결과와 방향 전환

Grok 단독 검수는 첫 수정 후에도 가림을 놓쳤고, 정상 원본에 이미 보이는 네 번째
발을 누락으로 판단했다. 반복 크롭을 시도하다 16턴을 소진한 실행도 있었다.
일반 지침을 더 붙이는 방식은 멈췄다. 대기 검수 취소는 PID 검색 실패로 실제
중단되지 않아 한 번 더 실행됐으며, 이미지 호출은 없었다. 잘못 남긴 취소 표시,
실제 실행과 비용을 함께 보존했다.

사용자가 지정한 것은 Grok CLI의 이미지 생성이므로 검수 책임을 Codex에 두었다.
같은 세 원본과 같은 조건으로 기존 지침·최종 지침을 각 한 번 비교했다. 기존판은
네 다리를 세고도 뒤 다리의 전체 길이가 드러나야 한다며 정상 후보를 탈락시켰고,
개선판은 원래 가시성 요구의 강도로 판단해 보존했다. 개수 오류·잎 가림은 두 판
모두 잡았다. 따라서 새로 확인한 스킬 효과는 정상 후보의 과도한 탈락 제거다.
표본 전체의 우월성이나 개수 인지 능력 향상으로 확대하지 않는다.

최종 파일은 네 다리 보정본, 세 잎이 가림 없이 보이는 배 그림, 정상 원본 그대로
세 개다. 실제 원본과 저장 파일을 열고 익명 독립 검수했다. 첫 배 그림은 네 핵심
항목을 통과했지만 원문의 먼 해안을 전경으로 옮겨 버렸다. 원문 전체를 보존한
해안 위치 편집 한 번으로 고쳤고, 앞서 통과한 개수·윤곽·색·빛·화면비를 다시
확인했다. 점토 질감은 여전히 명확히 식별되지 않아 미확인으로 남겼다. 핵심
검사표를 통과한 사실을 원문 전체의 완벽한 재현으로 부르지 않는다.

## 유지와 종료 판단

2.1.6은 위치별 개수 확인, 원문 가시성 강도 구분, 경계 접점 확인, 통과 후보
보존을 반영한다. 작은 부분은 문맥이 남는 상세 확인 한 번으로 제한하고, 그래도
불명확하면 누락으로 단정하지 않는다. 별도 판정기·출력 스키마·필수 외부 모델은
추가하지 않았다. Codex 검수와 Grok 생성 조합은 이번 사용자의 도구 선택이며
제품의 기본 도구나 지원 호스트 변경이 아니다.

재현한 결함과 실제 납품 결과는 확인했으므로 추가 생성은 종료한다. 사람 정답이
없는 모델 검수, 이미 알던 원본, 확률적인 이미지 생성, 재질·여백의 해석 한계는
남는다. 기존 G 미채택 기준은 재계산하지 않으며, 이번 수정은 알려진 결함의
제거와 최종 결과 확인으로 범위를 좁혀 채택했다. 모든 실행과 저장소 검증은
[연구 기록](../../research/2026-10-image-focused-repair/README.md)에 둔다.
