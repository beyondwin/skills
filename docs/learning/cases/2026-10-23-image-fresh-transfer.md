# 알려진 세 장을 벗어나도 이미지 검수 수정이 효과가 있는가?

시작일·기록일: 2026-10-23
관련 작업: image-workbench 2.1.6 새 요청 검증
결과: 일반 검수 대비 우위 미확인. 불필요한 중단 한 건만 고쳐 2.1.7 반영

사용자는 기존 세 사례에 맞춘 수정인지 확인하기 위해 새 요청 몇 개에서 스킬
미사용·사용을 같은 생성 예산으로 비교하고, 과도한 반복 없이 효과 있는 수정만
커밋하라고 요청했다. 이전 채택은 특정 요구 해석 결함의 제거이지 일반 우월성의
증명이 아니므로 새 자료에서 이를 분리해 확인한다.

새 요청 네 개와 평가 기준을 생성 전에 고정한다. 같은 최초 이미지를 양쪽에
주고 각 한 번의 보정 기회를 허용해 검수 차이와 최종 납품을 비교한다. 스킬은
첫 생성 원문을 보존하므로 이 공유가 가능하지만 첫 프롬프트 개선 효과를 검증하는
설계는 아니다. 정상 후보를 유지하면 남은 생성 기회를 억지로 쓰지 않는다.

처음부터 별도 판정기나 더 많은 표본을 추가하는 대안은 택하지 않는다. 판정은
원문과 익명 이미지로 독립 확인하고 모호함을 실패나 성공으로 바꾸지 않는다.
새 결함이 나타나면 작은 수정 한 번만 검토하며, 그때부터 해당 자료는 개발 자료다.
개선이 확인되지 않으면 제품은 바꾸지 않고 근거와 한계를 남긴다.

## 실제 결과와 한 번의 수정

새 원본은 반사가 있는 배 여섯 개, 완전히 노출할 열쇠 네 개, 손잡이가 일부 겹친
머그 세 개, 발 일부가 겹친 봉제 여우였다. 세 원본은 두 검토자가 정상으로
판단했고 미사용·2.1.6 모두 그대로 보존했다. 개수·가림 실패는 실제로 발생하지
않아 해당 탐지율 개선은 측정할 수 없었다. 실패가 나오도록 다시 생성하지 않았다.

열쇠는 네 물체가 모두 노출됐지만 한 물체의 이빨을 식별하기 어려웠다. 주 검토자는
미확인, 독립 검토자는 실패로 판단한 차이를 남겼다. 일반 검수는 한 번 편집해
고쳤지만 2.1.6은 보정 예산이 남아 있어도 중단했다. 이를 정상 후보 오탈락이나
가림 인지 실패로 세지 않고, 해결할 수 있는 모호함에서 불필요하게 멈춘 결함으로
구분했다.

수정은 미확인 후보를 통과시키지 않는 원칙과 보정 가능 여부를 분리하는 문장뿐이다.
관찰한 필수 부분의 모호함을 승인된 예산 안에서 명확히 할 수 있으면 한 번 보정하고
다시 검수한다. 권한·권리·도구·측정 불가로 인한 중단은 유지한다. 같은 네 원본을
개발 자료로 재확인했으며, 정상 세 장은 유지하고 열쇠만 원문 전체를 보존해 편집했다.

두 보정본의 독립 검수와 실제 최종 선택은 모두 통과했다. 일반 검수는 최종 4/4,
2.1.6은 3/4, 수정 후 2.1.7은 4/4였다. 따라서 확인된 효과는 기존 스킬의 중단
결함을 회복한 것이고 일반 검수보다 더 좋은 결과는 아니다. 정상 후보 오탈락은
양쪽 0/3으로 동률이며 미적 품질 우위도 관찰되지 않았다.

## 비용과 종료 판단

실제 이미지 호출은 공통 최초 네 장과 양쪽 보정 한 장씩, 총 여섯 번이다. 호스트
계약 확인은 보정 실행을 재사용하고 이미지 없는 세 호출로 끝냈다. 기존판이 새
이미지를 만들지 않은 최종 선택 재실행은 생략했다. 한 번의 수정 검증 때문에 Codex
세션은 최초 계획 네 번에서 총 다섯 번이 됐으며 이를 별도 비용으로 기록했다.

2.1.7은 실제 발견한 중단 결함만 고쳐 채택한다. 개수·가림 오판 감소나 일반 검수
대비 우월성을 입증하려고 표본을 추가하지 않는다. 새 네 요청은 이전 세 장만의
회귀를 넘어선 관찰이지만, 수정 이후에는 개발 자료이므로 일반화·과적합 해소를
단정할 수 없다. 사람 정답과 반복 표본이 없는 한계도 유지한다.
