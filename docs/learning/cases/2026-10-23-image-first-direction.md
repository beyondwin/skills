# 첫 생성에서 짧은 시각적 선택 보완이 실제 품질을 높이는가?

시작일·결정일: 2026-10-23. 상태: 비교 완료, 후보 미반영. 제품은 2.1.7 유지.

사용자는 검수 절차 증가 대신 첫 이미지의 실제 품질 향상을 요청했다. 이전의
광범위한 프롬프트 재작성은 품질·조건 준수가 악화됐고, 최근 검수 수정은 일반
검수와 동률이었다. Codex 검수의 효과를 Grok 단독의 이점으로 옮겨 주장할 수 없다.

이번에는 원래 요청 전체를 유지하고, 사용자가 정하지 않은 중요한 시각적 선택을
최대 두 개만 보완하는 후보를 시험한다. 이미 충분히 구체적인 요청에는 추가하지
않는다. 새로운 소품·주제·화풍을 넣거나 검수 단계를 늘리는 대안은 제외한다.

후보를 먼저 고정하고 다른 에이전트가 과거 사례와 후보를 읽지 않은 채 새 요청
네 개를 작성한다. 각 요청은 무스킬 Grok와 스킬 Grok가 각각 한 장만 생성한다.
프롬프트 작성·생성·자체 검수·저장은 Grok가 수행하고 다른 모델은 완료된 이미지의
익명 평가에만 참여한다. 일반 경로의 프롬프트 작성 자유를 제한하지 않는다.

두 평가자의 원문 기준 조건 준수, 네 완성도 항목, 쌍별 선호, 실제 최종 납품을
구분한다. 세 쌍 이상 합의된 우세·열세 없음, 평균 0.5점 이상 및 표준오차 두 배
초과, 요청별 조건 준수와 납품 악화 없음이 모두 필요하다. 후보와 표본을 바꾸거나
반복 생성해 통과시키지 않는다. 여덟 이미지 호출로 품질 비교를 종료한다.

## 실제 관찰과 결정

새 요청은 스피커 제품 사진, 달팽이 과슈 삽화, 새벽 바다 동굴, 주방 도구 정물이다.
Grok 단독으로 각 조건 한 번씩 총 여덟 장을 생성했고 수정·재시도는 없었다.
두 평가자의 평균 완성도는 일반 4.296875, 후보 4.25/5였다. 후보가 나은 쌍 한 개,
일반이 나은 쌍 두 개, 의견이 엇갈린 쌍 한 개로 사전 채택 기준을 충족하지 못했다.

달팽이 후보는 청록색 몸과 산호색 화분이 잘 분리돼 썸네일에서 더 잘 읽혔다.
하지만 실제 덧붙인 지시는 그 색상 분리를 직접 지정하지 않았으므로 원인으로
단정할 수 없다. 주방 도구는 일반 결과의 부드러운 빛·여백이 더 좋았다.
스피커 후보는 내려다보는 느낌이 강해 원문의 낮은 시점을 두 평가자 모두 미확인으로
남겼다. 동굴은 비대칭 회화적 표현과 차분한 중앙 구도에 대한 선호가 갈렸다.

조건을 모두 확인한 최종 파일은 일반 4/4, 후보 3/4이며 나머지 하나는 확정 실패가
아닌 미확인이다. 정상 후보를 잘못 버린 사례는 없었다. 구체적인 요청에도 두 문장을
추가했고, 이미 충분하면 추가하지 않는 동작은 확인되지 않았다. 원문을 보존한 채
짧게 보완하는 방법도 이번 표본에서는 일관된 첫 생성 이점을 만들지 못했다.

실제 네 후보 모두 SKILL 본문을 읽었다. 자동 판독기는 마지막 개행 하나가 달라
처음 false를 냈으며 전체 본문·작업 인자를 직접 대조해 해결했다. 모델을 다시
호출하거나 원래 판독 기록을 바꾸지 않았다. 별도로 네 후보 모두 필수 파일 검사기를
실행하지 않은 문제가 있었다. 감사자가 나중에 파일을 검사한 것을 Grok가 이행한
것처럼 보고하지 않는다. 생성 비교의 실행 확인과 전체 제품 계약 준수는 별개다.

추가 평가 에이전트 재개가 제한돼 주 작업자가 A 평가를 맡았다. A는 전략을 알고
있었지만 매핑·생성 프롬프트·생성기 판정·B 평가를 읽지 않았으며 두 점수를 먼저
고정했다. 다른 평가자는 독립적으로 익명 원본 여덟 장을 확인했다. 모델 평가이며
사람 선호나 반복 재현성을 입증하지 않는다.

## 종료와 남은 범위

유효한 수정만 반영하라는 요청에 따라 후보는 제품에 넣지 않는다. 기존 스킬·버전·
사용자 문서·스모크 기록을 바꾸지 않고 실제 비교 근거만 기록한다. 추가 생성,
이긴 한 사례만의 규칙 추출, 결과에 맞춘 기준 완화는 하지 않는다. 파일·점수·산술·
링크를 확인하되 제품이 그대로이므로 전체 테스트와 호스트 스모크를 반복하지 않는다.

첫 생성부터 무스킬보다 나은 스킬이라는 사용자의 목표는 아직 달성하지 못했다.
현재 근거는 일반적인 짧은 구도·빛 보완을 추가하는 것만으로 그 목표에 도달하지
못했다는 것이다. 이후 같은 처방을 반복하거나 검수 증가로 품질 향상을 대신 설명하지
않도록 실패한 전략과 실제 결과를 남긴다.
