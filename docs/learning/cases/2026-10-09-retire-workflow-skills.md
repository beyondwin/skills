# 작업 흐름 스킬 세 개를 왜 삭제했을까?

결정일: 2026-10-09. 기록일: 2026-10-09.
관련 작업: pre-sdd-review, sddx, waygent.
결과: 이전 모델에 유용했던 하네스의 필요성이 최신 모델의 성능 향상으로 줄었다는 사용자
판단과 pre-sdd-review 비교 실험을 근거로 세 스킬을 선셋했습니다.
근거 성격: 삭제·등록 목록 변경 커밋, 남아 있는 연구, 2026-10-09에 사용자가 직접
보충한 결정 이유입니다. 원래 삭제 요청 대화는 검토하지 않았으며, 이유는 이번 기록
갱신 대화에서 확인한 사후 설명으로 보존합니다.

## 시작한 문제

스킬이 일반적인 모델 작업보다 실질적으로 도움이 되는지 확인하는 비교 실험에서
출발한 판단입니다. 사용자는 해당 실험을 통해 판단한 뒤 pre-sdd-review, sddx,
waygent 세 스킬을 선셋했다고 이번 기록 갱신 대화에서 직접 설명했습니다.

초기 복원에서는 [삭제 커밋](https://github.com/beyondwin/skills/commit/c5a0251fe4ab9b2e052b410c70594d70e2d0f0fa)이
행동과 범위만 설명해 이유를 미확인으로 남겼습니다. 아래 사용자 설명으로 그 빈칸을
보완합니다. 처음부터 커밋에 이유가 적혀 있었던 것으로 소급하지 않습니다.

## 2026-10-09 사용자 설명으로 보완

**사용자는 이번 pre-sdd-review 대 일반 리뷰 실험 결과를 판단 근거로 삼아
pre-sdd-review, sddx, waygent 세 스킬 모두를 선셋했습니다.**

출처는 이 사례를 갱신하는 대화에서 사용자가 직접 제공한 설명입니다. 한 제품에만
해당하는 이유가 아니라 세 제품을 종료한 결정의 근거로 명시했습니다. 비공개 대화
원문 대신 이 요약을 보존합니다.

사용자는 이유를 더 설명하면서, 이전 모델에서는 이런 하네스가 효과적이었지만 최신
모델의 성능이 발달하면서 필요가 없어진 것 같다고 평가했습니다. **과거에 유용했던
보완 절차도 모델 자체의 능력이 좋아지면 추가 가치가 줄어들 수 있다**는 판단이며,
이번 실험 결과를 보고 세 스킬을 유지하지 않기로 한 맥락입니다.

과거의 효용과 모델 발전에 대한 설명은 사용자 경험·해석으로 기록합니다. 이번 실험은
최신 모델에서 일반 리뷰와 스킬을 비교했으며, 과거 모델과 최신 모델을 같은 조건으로
비교해 변화의 원인까지 검증한 실험은 아닙니다. 모든 종류의 하네스가 불필요해졌다는
일반 규칙으로 확대하지 않습니다.

## 당시 조건

세 제품은 삭제 직전까지 존재했습니다. 저장소에는 waygent와 pre-sdd-review에 관한
연구도 있었습니다. 해당 실험의 직접 비교 대상은 pre-sdd-review였으며, 작은 계획에서
추가 결함 발견 없이 시간·비용이 증가한 결과와 절차적 이점·한계를 담았습니다.
사용자는 이를 세 스킬의 유지 여부를 판단하는 근거로 사용했습니다. 이 선택을 기록하되
실험이 세 제품 모두의 모든 사용 상황을 직접 검증했다는 의미로 확대하지 않습니다.

## 대안과 선택

확인된 선택은 현재 트리에서 세 스킬의 배포 파일, 제품 테스트, 관리 문서를 삭제하고
Git 이력을 보존한 것입니다. 판단 근거는 위 비교 실험과 최신 모델에서 보완 절차의
필요성이 줄었다는 사용자 평가입니다. 제품별로 어떤
다른 대안을 검토했는지와 의도한 대체 수단까지는 이번 설명에서 제시되지 않았습니다.

## 확인한 결과

삭제 diff와 이후 제품 목록 리비전으로 무엇이 사라졌는지 확인할 수 있습니다.
남아 있는 [pre-sdd-review 보고서](../../research/2026-10-pre-sdd-review-eval/README.md#decision)는
실험만으로 일반적인 삭제 결론을 정당화할 수 없다고 한정했습니다. 실험한 작은 계획에서는
추가 결함 발견이 없었고, 추적 가능한 기록의 이점과 더 큰 사례는 측정하지 않았다는 한계를
설명합니다. 이는 실험 종료 당시 분석의 범위입니다. 이후 사용자는 해당 결과를 근거로
세 스킬을 선셋했다고 직접 밝혔으므로, 최종 유지 여부에 대한 결정은 그 설명에 따라 기록합니다.

[waygent 기록](2026-09-27-light-implementation-workflow.md)에도 구체적인 이점, 비용,
기각한 변경이 남아 있습니다. 어느 기록도 세 제품이 모두 실패했거나 모든 상황에서
불필요해졌음을 입증하지 않습니다. 이번 이력 복원을 위해 실행·품질 테스트를 하지 않았습니다.

## 유지와 종료 판단

이 저장소에서는 삭제됐습니다. 연구와 Git 이력은 근거로 남아 있으며 지원 별칭이나
호환용 코드는 없습니다. 세 스킬 선셋의 판단 근거는 사용자 설명으로 확인했습니다.
의도한 대체 수단과 재검토 조건은 미확인입니다. 삭제 당시 커밋과 나중에 보충한 이유의
출처·시점은 구분합니다.

2026-10-09 후속 기록: [pre-sdd-review 비교 사례](2026-10-08-pre-sdd-review-value.md)에
실험을 시작한 이유, 비교한 선택지, 좁은 오탐 수정을 채택한 이유를 추가로 보존했습니다.
실험과 수정은 삭제 전에 커밋됐습니다. 같은 날 사용자가 이 실험을 세 스킬 선셋의
판단 근거로 명시해, 실험 결과와 최종 선택 사이의 연결도 보완했습니다.
