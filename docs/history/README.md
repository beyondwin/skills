# 기록 / History

여기에는 아직 끝나지 않은 설계와 구현 계획만 둡니다. 옛 이름이나 경로가 남아 있을
수 있습니다. 이 파일들은 현재 계약을 정의하지 않습니다. 끝난 문서는 지웁니다.
Git 이력에서 볼 수 있습니다.

Files here are in-progress specs and plans. They may contain old names and
paths. They are point-in-time records, not the current contract. Finished files
are deleted; Git history keeps them.

지금 쓰는 안내는 [`docs/README.md`](../README.md), [`docs/users/`](../users/),
[`docs/maintainers/`](../maintainers/), 각 제품 README를 보세요.
