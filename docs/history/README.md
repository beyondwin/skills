# History

This folder holds only designs and plans that are still in progress. They are
point-in-time notes and may use old names or paths. They do not define the
current contract. Before deleting a completed or abandoned design, preserve its
significant decisions and outcome in a [learning case](../learning/README.md).
Then delete the working document; Git history keeps the original. Link its exact
commit and path from the case so readers can recover it. Learning cases survive
product retirement; keeping a historical record does not restore legacy support.

For current docs, see [`docs/README.md`](../README.md), [`docs/users/`](../users/),
[`docs/maintainers/`](../maintainers/), and each skill's README.
