# History

This folder holds only designs and plans that are still in progress. They are
point-in-time notes and may use old names or paths. They do not define the
current contract. Delete a file when its work ships; Git history keeps it.

For current docs, see [`docs/README.md`](../README.md), [`docs/users/`](../users/),
[`docs/maintainers/`](../maintainers/), and each skill's README.
