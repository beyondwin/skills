# sddx 4.0.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** sddx 4.0.0은 `/sddx`·`$sddx`만 발화하고, `extract_task.py --global-constraints`만으로 과제를 뽑으며, Superpowers 6.4.1의 태스크 묶음·중첩 native SDD를 덮어쓰고, 오케스트레이션은 이 세션의 모델·effort, 구현 effort는 과제마다 High 또는 XHigh다.

**Architecture:** 저장소 제품 계약에 sddx 전용 명시 발화 예외를 넣고, SKILL description·HARD-GATE·cases expect 잠금으로 발화를 닫는다. `extract_task.py`에 제약 절 이어붙이기 플래그를 추가한다. `dispatch.md` 앞에 컨트롤러 순서를 두고 `task-brief` 호출을 제거한다. 시작 때 구현 CLI를 한 번 고르고, 구현 `--effort`는 과제 난이도 표로 고른다. 워커 argv 스키마와 `run.json`은 그대로다. Grok에는 `--model`을 넣지 않는다.

**Tech Stack:** Python 3.11+ 표준 라이브러리, `unittest`, Git. 새 의존성 없음.

**Spec:** [docs/history/specs/2026-09-19-sddx-4.0.0-design.md](../specs/2026-09-19-sddx-4.0.0-design.md)

## Global Constraints

- 수정 대상은 `skills/sddx/`, `tests/products/sddx/`, `docs/maintainers/products/sddx/`, `scripts/lib/product_contract.py`, `tests/repository/test_repository.py`, `tests/repository/test_release_contract.py`만이다. 다른 제품 설치 파일의 암시 발화 정책은 바꾸지 않는다.
- Superpowers 파일을 고치지 않는다. SDD 본문을 이 스킬에 복사하지 않는다.
- `run_worker.py`, `resolve_backend.py`, `prepare_grok_sandbox.py`의 플래그, argv, `run.json` 스키마, 타임아웃, status 한도는 바꾸지 않는다.
- Python 3.11 이상, 표준 라이브러리만 쓴다.
- 지원 호스트는 `claude-code`, `codex`이다. 워커 argv를 바꾸지 않으므로 Cursor/Grok 라이브는 하지 않는다.
- 제품 버전은 `4.0.0`, 날짜는 `2026-09-19`이다. 태그와 GitHub Release는 만들지 않는다.
- 모든 테스트 명령은 저장소 루트에서 `PYTHONDONTWRITEBYTECODE=1`을 붙인다.
- 커밋 메시지는 `fix(sddx):`, `test(sddx):`, `docs(sddx):`, `chore(sddx):`를 따른다.

## Review Focus

- 사용자 메시지에 슬래시 없는 `sddx로 해줘`만 있다 → 스킬이 켜지지 않는다. Task 2 `near-miss-named-sddx-without-slash`.

```python
GLOBAL_CONSTRAINT_TITLES = frozenset({"Global Constraints", "Global constraints"})


def _section_bytes(
    lines: list[bytes],
    decoded_lines: list[str],
    start: int,
    end: int,
    heading: str,
) -> bytes:
    body = decoded_lines[start + 1 : end]
    if all(text.strip() == "" for text in body):
        raise ValueError(f"section {heading!r} has an empty body")
    return b"".join(lines[start:end])


def extract_task(
    plan: bytes,
    heading: str,
    *,
    global_constraints: bool = False,
) -> bytes:
    lines = plan.splitlines(keepends=True)
    decoded_lines = [line.decode("utf-8") for line in lines]
    headings = _scan_headings(decoded_lines)
    start, end = _select_section(headings, heading, len(lines))
    section = _section_bytes(lines, decoded_lines, start, end, heading)
    if not global_constraints:
        return section
    matches = [item for item in headings if item[2] in GLOBAL_CONSTRAINT_TITLES]
    if not matches:
        raise ValueError("no heading matches 'Global Constraints'")
    if len(matches) > 1:
        raise ValueError("heading 'Global Constraints' matches more than one section")
    c_start, c_level, c_title = matches[0]
    c_end = len(lines)
    for other_start, other_level, _ in headings:
        if other_start > c_start and other_level <= c_level:
            c_end = other_start
            break
    constraints = _section_bytes(lines, decoded_lines, c_start, c_end, c_title)
    return constraints + section
```
