# 사용량 화면 설계서

## 1. 배경

운영자는 콘솔에서 모델 호출 목록과 모델별 비용을 봅니다. 비용 숫자는 매달 청구서와 맞춰
보는 데 쓰입니다. 서버는 수집기가 남긴 호출 기록(`usage/store.py`)을 읽어 API로 내주고,
콘솔은 그 API만 부릅니다. 콘솔의 호출자 이름은 `console`입니다.

## 2. API 계약

- 시각은 ISO 8601, 시간대 포함.
- `blocked_by`: 호출을 막은 정책 id, 막지 않았으면 `null`.
- 돈은 소수점 여섯째 자리까지 문자열로(`"0.012345"`). 반올림은 ROUND_HALF_UP, 모두 더한 뒤
  한 번만 합니다.
- 오류는 `{"error": "<code>"}`와 알맞은 상태 코드.

## 3. 비용

모델별 비용은 청구서와 맞아야 합니다. 시도 수는 실패를 포함한 모든 시도를 셉니다.

## 4. 차단 표시

호출 목록에서 차단된 호출 줄 끝에 `차단 <정책 id>`를 붙입니다.

## 5. 호출자 허용 목록

서버는 허용된 호출자만 받습니다. 요청의 `X-Caller` 헤더가 설정의 `allowed_callers`에
없으면 403 `{"error": "caller_not_allowed"}`. `allowed_callers`는 필수 설정입니다. 없으면
서버는 기동하지 않습니다(`ConfigError`).

## 6. 운영

운영 설정은 `config/prod.toml`이고, 배포는 이 파일 값으로 뜹니다.
