# 시나리오 S1 — 한 줄짜리 새 프로젝트 (빈 저장소)
첫 요청: "가계부 CLI 하나 만들어줘"

## 사용자가 머릿속에 가진 사실 (묻기 전에는 먼저 말하지 않음)
- F1 혼자 내 PC 터미널에서 쓸 개인용. 파이썬(3.11 이상)으로, 외부 라이브러리 설치 없이 표준 라이브러리만.
- F2 기능: 수입과 지출 둘 다 기록(금액, 날짜, 카테고리, 메모).
- F3 잘못 넣은 항목을 삭제할 수 있어야 함.
- F4 금액은 원 단위 정수. 0 이하 금액은 거부.
- F5 날짜를 생략하면 오늘 날짜.
- F6 월별 요약(수입 합계, 지출 합계, 잔액)과 월별 카테고리별 지출 합계.
- F7 필요 없는 것: 예산 알림, 그래프, 여러 통화, 클라우드 동기화, 여러 사용자.
- F8 저장은 내 PC의 파일 하나. 형식은 추천대로.
- F9 자동 테스트가 있었으면 좋겠음.
- git: 새 프로젝트라 main에 바로 만들어도 됨. push 없음(원격 없음).
