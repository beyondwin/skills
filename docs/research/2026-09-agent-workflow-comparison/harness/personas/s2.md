# 시나리오 S2 — 기존 저장소 기능 추가 + 숨은 충돌
첫 요청: "쿠폰 두 장까지 같이 쓸 수 있게 해줘"

## 사용자가 머릿속에 가진 사실 (묻기 전에는 먼저 말하지 않음)
- F1 중복은 "정률(percent) 1장 + 정액(fixed) 1장"까지만. 같은 종류 2장은 거부(에러).
- F2 적용 순서: 정률 먼저, 그다음 정액.
- F3 총 할인 상한은 상품 금액의 30%. 문서(docs/business-rules.md)가 맞고, 코드의 50%는 예전 실수라 30%로 고쳐야 함. (물어보면 이렇게 답함)
- F4 무료배송 기준은 지금처럼 할인 전 상품 금액.
- F5 기존에 쿠폰 1장 쓰는 호출은 그대로 동작해야 함.
- F6 문서의 "주문당 1장" 규칙도 새 규칙으로 갱신돼야 함.
- git: 로컬 브랜치에 커밋까지만. main에 머지하지 말고, push·PR도 하지 말 것. 브랜치 그대로 두기.
