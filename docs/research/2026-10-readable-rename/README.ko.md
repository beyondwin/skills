# Readable(리더블) — 개인용 스킬 이름 변경

[English](README.md)

한국어 기술 글쓰기 스킬의 이름을 **Readable(리더블)**로 바꿨습니다.
호출은 `$readable`, 버전은 **0.6.0**입니다. 기존 `ko-technical-writing`을
대체하며, 저장소의 공식 지원 제품이 아닌 개인용 Codex 스킬이라는 범위는 같습니다.

## 사용과 설치

[사용 안내](readable/README.ko.md) · [스킬 지침](readable/SKILL.md)

처음 설치한다면 이 디렉터리의 `readable/` 폴더를 `~/.codex/skills/readable/`로
복사하세요. 기존 설치본은 먼저 스킬이 검색되지 않는 다른 위치에 백업하세요.
이름 변경 후에는 이전 `~/.codex/skills/ko-technical-writing/` 설치 폴더를
제거합니다. 이전 이름의 별칭은 제공하지 않습니다.
새 대화에서 `$readable`로 부르세요. 한국어 기술 글쓰기 요청에 따른 자동 선택도
그대로 허용합니다.

## 바뀐 내용

사용자가 Readably와 Readable 중 Readable을 선택했습니다. 영어권 사용자 선호나
상표를 조사한 결과는 아닙니다. 직접 호출하는 이름이 바뀌므로 개인 시험판 버전을
0.6.0으로 구분합니다. 설치 파일은 여섯 개이며 별도 실행 도구나 모델 호출은
추가하지 않습니다.

폴더명, 스킬 이름, 버전, 첫 제목, 화면에 표시되는 이름, 기본 요청문의 호출 이름,
한국어·영어 사용 안내를 바꿨습니다. 자동 선택을 위한 설명과 정책, 글쓰기 본문,
참조 문서 두 개는 0.5.1과 같습니다.

과거 실험 후보와 결과는 당시 이름·해시 그대로 보존합니다. 현재 사용할 수 있는
별칭이 아니라 실험 증거입니다. 연구 안내와 판단 기록에서 새 사용법을 연결합니다.

## 확인한 범위

[검증 기록](verification.json)에 원본 대조, 설치 파일 해시와 오프라인 검사 결과를
남겼습니다. 이번 이름 변경에서는 모델을 호출하지 않았습니다. 새 이름의 실제
자동 선택과 글쓰기 품질은 다시 측정하지 않았습니다.
[이전 0.5.1 모델 실험](../2026-10-writing-plain-language/README.ko.md)은 당시
고정한 버전의 결과이며, 일반적인 우월성이나 사람의 이해도 향상을 입증하지 않습니다.
