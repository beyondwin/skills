# Readable(리더블) — 개인용

[English](README.md)

0.6.0은 자료를 바탕으로 기술 문서, 운영 절차, 인계문, 커밋 메시지와 PR 설명을
작성합니다. 낯선 개념은 누가 무엇을 하는지 풀어서 설명합니다. 코드 이름과 명령,
조건, 확인되지 않은 사실은 원래 의미를 지킵니다.

`$readable`을 지정하거나 한국어 기술 문서 작성을 요청하세요.
자동 선택도 가능합니다. 처음 설치할 때는 이 폴더를
`~/.codex/skills/readable/`에 복사하세요. 기존 설치본이 있다면 먼저
백업하세요. 갱신한 뒤 새 대화에서 사용하세요. 삭제할 때는 해당 폴더만 지우면 됩니다.

현재 모델만 사용하며 별도 모델 호출, 훅, 린터는 필요하지 않습니다. 변경 내용을
설명하려면 Git이 필요합니다. 글쓰기 요청만으로 커밋, 게시, 테스트, 배포를 실행하지
않습니다. 제공한 글의 교정은 별도 korean-writing-editor의 범위이며 필수 설치는
아닙니다. 번역만 하는 작업과 일상 대화는 이 스킬의 범위가 아닙니다.

개인용 Codex 스킬이며 저장소의 공식 지원 제품은 아닙니다. 명확한 글쓰기 원칙을
응용했지만 ASD-STE100 인증을 뜻하지 않습니다. 모델 평가와 작성자 검토만으로
사람의 선호나 읽기 속도가 입증되지는 않습니다. 0.6.0은 이름을 바꾼 버전이며
글쓰기 지침은 0.5.1과 같습니다. 호출 이름은 `$readable`이며 이전 이름의 별칭은
설치하지 않습니다. 실제 모델 실험은 0.5.1의 결과이고, 이름 변경은 오프라인으로
검증했습니다.
