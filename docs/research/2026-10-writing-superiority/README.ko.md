# 한국어 기술 글쓰기: 우월성 비교 결과

[English](README.md) · [이전 실험](../2026-10-writing-readability/README.ko.md)

**우월성은 아직 입증하지 못했습니다. 설치본은 0.2.2를 유지합니다.** 새 후보가
선호된 사례는 더 많았지만, 실행 전에 정한 채택 기준에는 못 미쳤습니다. 이는 효과가
없다는 확정도 아닙니다. 수정본의 회귀 통과와 읽기 품질의 우월성은 별개입니다.

## 새 과제 12개를 비교한 결과

설명문·운영 절차·인계문·측정 보고서를 Codex, Opus, Grok에 각각 하나씩 배정했습니다.
각 과제를 일반 작성, 0.2.2, 새 0.3.0으로 작성한 뒤 다른 제공자가 버전 없이 두 순서로
평가했습니다. 같은 과제의 두 평가가 일치할 때만 승패로 집계했습니다.

| 0.3.0의 비교 대상 | 승리 | 패배 | 동률·순서 불일치·누락 | 단측 확률 |
| --- | ---: | ---: | ---: | ---: |
| 일반 작성 | 7 | 1 | 4 | 0.03515625 |
| 설치된 0.2.2 | 3 | 0 | 9 | 0.125 |

두 비교에서 각각 8승 이상, 확률 0.025 이하, 전체 평가 완료, 의미 보존과 실제 설치
검증을 모두 요구했습니다. 기준을 통과하지 못했습니다. 과제마다 작성은 한 번씩이며,
작성자가 만든 합성 과제입니다. 사람의 이해도·읽기 속도·자연스러움 측정은 아닙니다.

주 비교는 62회 호출해 61개 답변을 받았습니다. 작성 36개, 비교 평가 24개 중 23개,
평가자 점검 2개입니다. Grok 평가 한 건이 480초에 종료됐으며 재시도하지 않았습니다.
누락을 패배로 세지 않았습니다. 누락 한 건이 유리하게 나왔더라도 기존 버전과의 비교는
기준에 못 미칩니다. 호출 수는 독립 과제 수나 HTTP 요청 수가 아닙니다.

## 발견한 문제와 수정

0.3.0은 독자의 질문에 맞춰 근거를 고르고 인과 관계를 연결하도록 바꿨습니다. 하지만
반복은 남았고, 세 모델 모두 0.2.2보다 글이 길고 작성 시간 중앙값도 늘었습니다.
삭제 응답을 설명하는 첫 문장이 예외를 빠뜨리고 적용 범위를 넓힌 문제도 발견했습니다.

0.3.1은 첫 문장에 조건을 보존하고, 질문과 무관한 수명 주기 설명을 제외하며,
대표성 미확인과 대표성 부재를 구분하도록 보완했습니다. 새 설명 과제 두 개를 세 모델로
검사하고 커밋·JSON·서브모듈 회귀를 확인했습니다. 9개 답변 중 작성자 대조에서 7개가
통과했습니다. Opus의 인가/인증 혼동과 Grok의 불확실성을 부정으로 바꾸는 오류가 남았습니다.

0.3.2는 이 두 구분을 추가로 보완합니다. 같은 설명 과제 여섯 번과 JSON 한 번으로
별도 재검사했습니다. 작성자 원자료 대조에서 7/7을 통과했습니다. 다만 Grok의
어색한 표현은 일부 남았습니다. 이 결과는 이미 확인한 결함의 회귀 근거이며 새로운 블라인드
우월성 비교가 아닙니다. 세 후보는 연구 자료로 남기며 개인 설치본을 교체하지 않습니다.

이번 작업 전체는 **78회 호출·77개 답변**입니다. [통합 집계](study-summary.json)와
[0.3.2 검사 결과](final-results.json)에 라운드별로 남겼습니다. 설치 후 검사는 새 후보를
채택하지 않았으므로 실행하지 않았습니다.

## 평가 모델도 틀렸습니다

두 평가자는 일부러 바꾼 임계값과 반복 문장을 찾아냈습니다. 그러나 Grok은 A와 B를
비교한 표현을 B 자체의 과거 변화로 오해하거나, 503 재시도가 안전하지 않다는 경고를
401 재시도는 안전하다는 뜻으로 해석하기도 했습니다. 원래 선호 결과는 그대로 남기고,
[원자료 대조](adjudication.md)에서 이런 과도한 해석을 구분했습니다. 높은 모델 점수를
얻는 것만으로 자연스러운 글이 검증되지는 않습니다.

현재 0.2.2와 일반 작성의 익명 비교 자료 세 쌍도 준비했습니다. 사후에 고른 자료이며
개인 취향을 확인하기 위한 것입니다. 사람의 답변은 아직 없고, 화면 기능을 시험할 때
누른 값은 평가에 포함하지 않았습니다. 단순화한 공통 Markdown 표시를 사용했습니다.
로컬 파일: `/Users/kws/Downloads/ko_writing_reading_check_20261009/index.html`.
