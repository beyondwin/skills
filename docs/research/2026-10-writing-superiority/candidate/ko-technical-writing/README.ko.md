# 한국어 기술 글쓰기 — 개인용 시험판

[English](README.md)

독자가 원인과 조건, 다음 행동을 쉽게 이해하도록 실제 근거에서 기술 문서, 운영 절차,
커밋 메시지, PR 설명, 인계문을 작성합니다.
0.3.0은 개인용 Codex 시험판이며 상위 저장소의 네 번째 지원 제품이 아닙니다.
현재 모델을 사용하며 별도 모델 서비스·훅·린터는 필요하지 않습니다. Git 변경을
확인하는 작업에는 Git이 필요합니다.

이 폴더를 `~/.codex/skills/ko-technical-writing/`에 복사합니다. 기존 설치가 있다면
덮어쓰지 않습니다. 새 대화를 시작하면 갱신된 스킬 목록을 사용할 수 있습니다.
자동 선택을 허용하며 `$ko-technical-writing`으로 직접 지정할 수도 있습니다.

사용 예:

- `$ko-technical-writing docs/status.md를 읽고 다음 작업자를 위한 인계문을 써줘.`
- `스테이징된 변경만 설명하는 한국어 커밋 메시지를 작성해줘.`
- `이 운영 메모를 바탕으로 실패 분기를 보존한 운영 절차서를 써줘.`

중요한 경우 독자·출력 언어·저장할 경로를 요청에 함께 적습니다. 저장 요청이 없으면
초안을 답변합니다. 글을 쓴다는 이유만으로 Git 커밋, PR 제출, 발행, 테스트 실행,
배포까지 수행하지 않습니다.

제공된 원문의 교정은 `korean-writing-editor`의 역할입니다. 이 스킬을 쓰기 위해
교정기를 설치할 필요는 없습니다. 번역만 하는 요청, 일상 대화, 코드 리뷰 자체,
교사용 제품 문구도 적용 대상에서 제외합니다.

명확한 글쓰기 원칙을 응용한 도구이며 ASD-STE100 인증이나 한국어 의미 검증기가
아닙니다. 모델의 대조도 틀릴 수 있습니다. 측정 환경과 한계는 상위 연구 기록에서
확인할 수 있습니다. 전역 AGENTS나 프로젝트 정책을 추가할 필요는 없습니다.

제거하려면 이번에 설치한 `ko-technical-writing` 폴더만 삭제합니다. 되돌릴 다른
설정은 없습니다.

0.3.0에서는 독자가 궁금해할 순서로 설명을 구성하고, 관계를 문장으로 연결하며,
구체적인 동사를 사용합니다. 초안에서 반복과 모호한 지시어도 점검합니다. 후속 연구는
모델의 비교 평가이며 사람의 읽기 속도나 이해도 향상을 입증한 실험은 아닙니다.

0.3.0은 실제 실행에서 발견한 반복 설명, 절차의 앞부분을 다시 찾아보게 하는 참조,
백분위 지표의 확대 해석을 보완합니다. 별도 보정 검사를 수행하며 0.2.0의 블라인드
평가 점수를 최종 버전의 점수로 옮겨 쓰지 않습니다.

Grok 실행에서 표와 본문의 수치가 달랐던 문제를 반영해, 숫자 표의 각 열을 원자료의
대상·단위·상태와 대조하고 본문에서 반복한 값도 일치하는지 확인합니다.
