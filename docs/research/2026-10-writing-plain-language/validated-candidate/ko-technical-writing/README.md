# Korean Technical Writing — personal pilot

[한국어](README.ko.md)

Version 0.5.1 writes Korean technical documents, runbooks, handoffs, commit messages
and PR descriptions from evidence. It explains unfamiliar concepts through concrete
actors and actions, while preserving identifiers, conditions and uncertainty.

Use `$ko-technical-writing` or ask for a Korean technical draft. Automatic selection
remains enabled. Copy this folder to `~/.codex/skills/ko-technical-writing/` for a
new installation; back up an existing installation before replacing it. Start a new
session after an update. Remove that folder to uninstall.

The skill uses the active model, with no extra model call, hook or linter. Git is
needed for change descriptions. Drafting does not authorize a commit, publication,
test run or deployment. Supplied-prose proofreading belongs to korean-writing-editor;
that other skill is not a dependency. Translation alone and casual chat are excluded.

This is a personal Codex pilot, not a supported product of the parent repository.
It adapts clarity principles and does not certify Korean text against ASD-STE100.
Model checks and author review do not establish human preference or reading speed.
See the containing study for adoption status and the actual validation scope.
