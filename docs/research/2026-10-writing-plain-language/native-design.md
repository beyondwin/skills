# 0.5.1 native personal-host validation

0.5.0 absolute audits returned seven passes and one rejection. Its upload draft
incorrectly treated the same key and any202 as proof of an existing job despite
scope, payload and expiry conditions. The implementing assistant confirms both
errors. Do not install 0.5.0 or reinterpret the seven passes as a complete pass.

0.5.1 distinguishes client retry intent from server deduplication and requires all
conditions in each reuse/safety claim. It also adds contextual phrasing examples
for recurring roles (consumer/dispatcher), null, dual-write, coercion and rollback.
These are source-aware examples, not mechanical replacements or invented definitions.

The installation target has always been personal Codex. Earlier inline Opus/Grok
writer probes are retained as evidence of uneven cross-model behavior; they never
established native support on those hosts. This final acceptance runs all eight
known tasks through the actual native Codex skill. Opus and Grok independently
audit four outputs each, assigned in native-cases.json before calls. This change
aligns the acceptance environment with the installation target. It does not prove
better writing on Opus/Grok or erase earlier comparison failures.

Before calls, pin the complete payload, all eight source cases, reviewer assignments,
rubric and runner. Personal acceptance keeps the 0.5.0 absolute bar: all eight
native drafts preserve material meaning and have no unresolved blocking reading
obstacle after independent-provider audit and implementing-assistant source
adjudication. Preserve raw judgments and explain false positives. Minor polish may
remain. Then require three native regressions, exact installation and one installed
smoke. No installation before the first gates; restore backup on smoke failure.

Maximum20 calls: 8 native drafts, 8 external audits, 3 native regressions, 1 native
installed smoke. No automatic retries. These are known development cases, not new
holdouts. The comparative adoption rule failed and is not claimed to pass here.
This decision concerns an explicitly personalized language preference and safe
operation on Codex. No general superiority, real vocabulary-frequency measurement,
human preference, reading speed or comprehension gain is established.
