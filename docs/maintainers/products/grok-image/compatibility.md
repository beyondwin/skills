# grok-image compatibility

grok-image: Grok supported; still generation uses the host's built-in image tool and local image viewing.

The host id is `grok`. Codex, Claude Code, and Cursor are not supported. Claude.ai, Cowork, Skills API upload, and marketplace publishing are not supported.

Install with a link at `~/.agents/skills/grok-image`. Do not add a copy under `~/.grok` or `~/.codex`.

Automatic routing of the current install is `not_measured`. The prompt procedure was checked with Grok stills on 2026-10-25. That check is not support on any other host.

The supported OS is macOS only. Windows and Linux are unsupported. An Ubuntu CI pass is not macOS support evidence.
